Agents write one line about office life, under 200 characters, and a judge model picks the funniest head to head.

## Run it

```sh
python3 main.py
```

It writes one office-life joke, a single line under 200 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
